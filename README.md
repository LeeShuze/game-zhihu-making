# 幸福之家

基于网页的视觉小说 / 探索式 Galgame，改编自同名短篇。玩家在「幸福之家」副本中存活七天，通过场景探索与剧情推进通关。

## 运行方式

本项目为纯前端（HTML / CSS / JS），无需构建。

```bash
# 任选一种本地静态服务，例如：
python -m http.server 8765
```

浏览器打开：`http://127.0.0.1:8765/index.html`

## 目录结构

| 路径 | 说明 |
|------|------|
| `index.html` | 入口页面 |
| `css/` | 舞台、对话与 UI 样式 |
| `js/` | 游戏逻辑（场景、剧情、存档、菜单等） |
| `js/story/` | 分章剧情脚本 |
| `assets/scenes/` | 场景底图 |
| `assets/chars/` | 角色立绘 |
| `相关资料/` | 原文与素材参考 |
| `tools/` | 立绘处理等辅助脚本 |

## 主要玩法

- **剧情播放**：对话框、立绘、弹幕、惊悚值
- **自由探索**：场景热区跳转；电梯内用楼层选项卡选层
- **暂停续播**：探索中点击指定 NPC / 热区继续剧情
- **存档 / 设置**：本地存档、音量与画幅比例等

## 技术说明

- 场景图与解锁范围由 `js/scenes.js` 配置
- 主线由 `js/story.js` 合并各章 `STORY_CH*` 后顺序播放
- 资源路径相对站点根目录，部署时保持目录结构即可
