# 幸福之家

基于网页的视觉小说 / 探索式 Galgame，改编自同名短篇。从知乎入口进入副本，经值班室与停车场电梯抵达 30 层后继续剧情。

## 运行方式

需要 Node.js。在本目录执行：

```bash
npm start
```

浏览器打开：http://127.0.0.1:8765/

不要用 `python -m http.server`，也不要双击 HTML。停车场模型很大，需正确的静态服务。

## 流程

1. 知乎书架选择故事并进入副本  
2. 楼前剧情播到「死亡之家」弹幕结束 → 3D 值班室（钥匙 + 手电）  
3. 停车场乘电梯到 30 层 → 回到 30 层门外敲门，继续 AVG

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` | 知乎入口 |
| `duty/` | 3D 值班室 |
| `elevator/` | 3D 停车场与电梯 |
| `avg/` | 视觉小说主体（对话、探索、存档） |
| `scripts/serve.mjs` | 本地 8765 静态服务 |
| `tools/` | 立绘处理等辅助脚本 |

## 主要玩法

- **剧情播放**：对话框、立绘、弹幕、惊悚值
- **自由探索**：场景热区跳转；电梯内用楼层选项卡选层
- **暂停续播**：探索中点击指定 NPC / 热区继续剧情
- **存档 / 设置**：本地存档、音量与画幅比例等
