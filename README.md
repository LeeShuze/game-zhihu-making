# 幸福之家

基于网页的视觉小说 / 探索式 Galgame，改编自同名短篇。从知乎入口进入副本，经值班室与停车场电梯抵达 30 层后继续剧情。

## 运行方式

需要 Node.js。在本目录执行：

```bash
npm start
```

浏览器打开：http://127.0.0.1:8765/

不要用 `python -m http.server`，也不要双击 HTML。停车场模型很大，需正确的静态服务。

## 流程

1. 知乎书架选择故事并进入副本  
2. 楼前剧情播到「死亡之家」弹幕结束 → 3D 值班室（钥匙 + 手电）  
3. 停车场乘电梯到 30 层 → 回到 30 层门外敲门，继续 AVG

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` | 知乎入口 |
| `duty/` | 3D 值班室 |
| `elevator/` | 3D 停车场与电梯 |
| `avg/` | 视觉小说主体（对话、探索、存档） |
| `scripts/serve.mjs` | 本地 8765 静态服务 |
| `tools/` | 立绘处理等辅助脚本 |

## 主要玩法

- **剧情播放**：对话框、立绘、弹幕、惊悚值
- **自由探索**：场景热区跳转；电梯内用楼层选项卡选层
- **暂停续播**：探索中点击指定 NPC / 热区继续剧情
- **存档 / 设置**：本地存档、音量与画幅比例等


## 手机横屏适配（本地待体验）

同一网址自动判断触屏设备与屏幕尺寸。手机或平板使用触屏配置，竖屏显示横屏提示；电脑保留原布局和原模型。识别依据为 coarse 指针、触点数量和屏幕短边，不单靠浏览器名称。部分浏览器无法锁定横屏，需手动旋转并关闭系统竖屏锁定；支持的浏览器可点击“全屏”。

- 入口：滑动书架、轻点书本，详情区域可滚动。
- 值班室：拖动画面观察，轻点钥匙与手电查看，点“收入囊中”；集齐后点“前往 30F”。
- 电梯：左侧摇杆移动、右侧画面拖动观察，右下角点按手电，左上角暂停；门开后可点击“走出电梯”。转为竖屏会暂停行走，横过来后点击继续探索。
- AVG：轻点推进，选择选项或热区探索；菜单、存档和设置适配横屏高度，较长内容可滚动。转竖屏会关闭自动和跳过模式，避免背后继续推进。

手机资源是独立 GLB，普通贴图降一级、最大 1K，512px 及以下的小贴图保留；电脑文件未覆盖。16 个场景模型共约 211 MB → 59 MB。网格、材质参数、碰撞和动画保留。手机 3D 渲染倍率上限 1.5，值班室恢复抗锯齿并采用轻量后处理配置，电梯降低阴影分辨率并关闭屏幕空间接触阴影；手机不做下一段高清资源预取。

测试开关：`?device=mobile` 强制手机配置；`?device=desktop` 强制电脑配置；`?device=auto` 恢复自动。选择保存在当前标签页 sessionStorage，跨场景继续生效。强制手机布局不能把电脑鼠标变成真正的双指触屏，请在真机确认手感。

本机真机预览：让手机与电脑连接同一 Wi-Fi，运行 `HOST=0.0.0.0 PORT=8766 npm start`，手机访问电脑局域网 IP 的 8766 端口。不要在手机上用 localhost 指向电脑。预览由本地电脑提供，关闭服务后地址失效。

开发检查：`npm ci` 后执行 `npm test`。测试覆盖识别、跨页测试开关、横竖屏状态、双指控制，以及通过 Three.js / Meshopt 实际解析移动版几何。重新生成移动模型需 Python + Pillow，执行 `python3 scripts/build-mobile-models.py`。生成过程中会验证几何与压缩数据未变；报告在 mobile/models.json。

当前未执行浏览器或视觉验收，布局、触控手感和帧率仍需 iPhone / Android 真机体验，静态与 Node 检查不代表实测性能。

手机线索阅读：任务纸、档案板、文件夹和调查照片使用未压缩的独立原图。文件夹、档案板可点击“放大阅读”到 1.35 倍，拖动查看文字，再点“还原”或“关闭”；任务纸与公告板照片按适屏原图查看；值班室纸面绘制精度提升到 2K。环境模型仍使用轻量贴图。

Safari 地址栏无法由网页强制隐藏，游戏按实际可见高度适配。正式网址可通过 Safari 分享菜单添加到主屏幕（如有“作为网页 App 打开”，请开启），从桌面启动获得无地址栏体验。浏览器内的“全屏方式”提供操作说明。

手机值班室补充：电脑界面外另有“退出电脑”按钮；电话说明直接显示全文，避免逐字音效与刷新造成卡顿。
